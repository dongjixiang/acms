## 一、本次新增功能

### 1. 流式响应优化 ✅

**问题**：
- 长回复时频繁 DOM 更新影响性能
- 无暂停/继续控制
- 无速度调节
- 网络中断无自动重试

**解决方案**：
| 功能 | API | 说明 |
|------|-----|------|
| 暂停 | `buddyStreamPause()` | 暂停流式推送 |
| 继续 | `buddyStreamResume()` | 恢复流式推送 |
| 停止 | `buddyStreamStop()` | 立即停止 |
| 调速 | `buddyStreamSetSpeed(ms)` | 10-100ms 可调 |
| 重试 | 内置 | 网络中断自动重试 3 次 |

**UI 控件**：
- ⏸ 暂停/继续按钮（面板 header）
- ⚡ 速度调节按钮（循环切换 5 档速度）

---

### 2. 主动建议系统 ✅

**问题**：
- 缺乏智能建议功能
- 用户不知道系统有什么可以做的

**解决方案**：
- LLM 智能分析用户行为和系统状态
- 生成具体可操作的建议
- 基于规则的降级方案
- 冷却机制（至少 2 小时生成一次）

**API 端点**：
```
GET /api/agent-buddy/suggestion
```

**返回示例**：
```json
{
  "ok": true,
  "suggestions": [
    {
      "type": "task",
      "priority": "high",
      "title": "有待审核任务",
      "content": "你有 2 个任务等待审核，请及时处理。",
      "action": "view_task"
    }
  ],
  "reason": "基于当前任务状态生成"
}
```
