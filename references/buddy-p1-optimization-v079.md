## 二、详细变更

### 2.1 移除 jsmebed 模式

**根因**：jsEmbedding 模式与 BGE 语义检索效果重复，增加维护成本。

**修改文件**：
- `server/services/tool-retriever.js` — 删除 jsmebed 分支逻辑
- `server/routes/agent-buddy.js` — 删除模式校验中的 jsmebed 选项

**验证**：
```bash
# 正常模式
POST /api/agent-buddy/tool-retriever/mode {"mode":"embedding"}
→ { "ok": true, "mode": "embedding" }

# 无效模式返回错误
POST /api/agent-buddy/tool-retriever/mode {"mode":"invalid"}
→ { "ok": false, "error": "mode must be \"keyword\", \"bge\", or \"embedding\"" }
```

---

### 2.2 图片搜索质量提升

**新增函数**：
- `browserSearchDDGImage(query, maxResults)` — DDG 图片搜索备用方案

**使用场景**：
- 用户说"找图片""搜索壁纸"等
- 触发关键词：`图片|照片|写真|壁纸|头像|海报|截图|相片|图集|靓照|艺术照`

**返回格式**：
```json
{ "images": [{ "thumb": "...", "url": "...", "title": "..." }] }
```

---

### 2.3 工具描述结构化

**优化目标**：让 LLM 更容易理解工具使用场景和约束。

**修改的工具**：

#### `web_search`
```javascript
【用途】联网搜索最新信息、事实、数据
【适用】用户明确说"搜一下"/"查一下"/"XX是什么"/"最近XX事件"
【禁用】用户描述产品功能、场景、想法、需求时严禁调用
【返回】1-50条结果（标题+摘要+URL），默认50条
【参数】
  - query: 搜索关键词（必填，中文或英文）
  - max_results: 结果数量（1-50，默认50）
【示例】
  - ✅ 正确："帮我搜一下2026年世界杯足球赛冠军是谁"
  - ❌ 错误："帮我做一个世界杯相关的功能页面"
```

#### `web_research`
```javascript
【用途】深度综合调研（搜索+抓取+LLM综合分析）
【适用】用户明确要求：1)调研产品/行业/公司 2)深度对比多个方案 3)总结某主题最新进展
【禁用】用户描述产品功能、场景、需求时严禁调用
【返回】结构化答案（含引用来源）
【参数】
  - query: 调研问题或主题（必填）
  - max_results: 搜索条数（1-50，默认50）
  - deep_fetch: 自动抓取URL数（0-10，默认10；0=只搜索不抓取）
  - model_id: 分析用LLM（可选，默认用系统默认模型）
```
