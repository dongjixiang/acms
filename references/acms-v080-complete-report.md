## 二、本次新增功能（v0.80）

### 2.1 流式响应优化 ✅

**问题**：
- 长回复（>500 字）时频繁 DOM 更新影响性能
- 无暂停/继续控制
- 网络中断后无自动重试

**解决方案**：
| 功能 | API | 说明 |
|------|-----|------|
| 暂停 | `buddyStreamPause()` | 暂停流式推送 |
| 继续 | `buddyStreamResume()` | 恢复流式推送 |
| 停止 | `buddyStreamStop()` | 立即停止 |
| 调速 | `buddyStreamSetSpeed(ms)` | 10-100ms 可调 |
| 重试 | 内置 | 自动重试 3 次 |

**使用示例**：
```javascript
// 在浏览器控制台调用
window.buddyStreamPause();   // 暂停
window.buddyStreamResume();  // 继续
window.buddyStreamSetSpeed(20); // 加速到 20ms
window.buddyStreamStop();    // 停止
```

---

### 2.2 主动建议系统 ✅

**问题**：
- 缺乏智能建议功能
- 用户不知道系统有什么可以做的

**解决方案**：
- LLM 分析用户行为和系统状态
- 生成具体可操作的建议
- 基于规则的降级方案
- 冷却机制（至少 2 小时生成一次）

**API 端点**：
```
GET /api/agent-buddy/suggestion
```

**返回示例**：
```json
{
  "ok": true,
  "suggestions": [
    {
      "type": "task",
      "priority": "high",
      "title": "有待审核任务",
      "content": "你有 2 个任务等待审核，请及时处理。",
      "action": "view_task",
      "actionTarget": "review"
    }
  ],
  "reason": "基于当前任务状态生成"
}
```

## 五、技术细节

### 5.1 流式响应架构

```
前端                          后端
  |                             |
  |-- POST /chat?stream=1 ---->|
  |                             |-- 生成回复
  |<-- SSE: text chunks -------|
  |   (30ms/块，可调速)        |
  |<-- SSE: action -----------|
  |                             |
  |-- 网络错误 ---------------->|
  |   (自动重试 3 次)           |
  |                             |
  |-- AbortController -------->|
  |   (用户主动停止)           |
```

### 5.2 主动建议架构

```
定时检查 (每 15 秒)
    |
    v
冷却时间检查 (≥2 小时)
    |
    v
收集用户上下文
    |-- 项目列表
    |-- 需求状态
    |-- 任务状态
    |-- 缺陷状态
    |
    v
LLM 分析
    |-- 成功 → 返回智能建议
    |-- 失败 → 规则降级
    |
    v
返回建议列表
```
