事件总线 · Event Bus

通信层 ▾

ACMS 内部通信中枢。所有 Agent 组件通过事件驱动解耦，不直接调对方代码。

task-agent →emit→ task.completed → dispatcher / 小吉 / reviewer
task-agent →emit→ task.failed → dispatcher(重试) / 小吉(弹面板)
task-agent →emit→ task.review_rejected → dispatcher / 小吉
dispatcher →emit→ task.claimed → task-agent(触发执行)
用户 →WebSocket→ task.* / agent.* →CustomEvent→ 小吉(弹面板+加分)

多角色流水线 · Multi-Role Pipeline

执行引擎 ▾

串行 4 角色（或 2 角色），每角色独立 system prompt + 工具子集，天然交叉验证。 文档/重构/测试类 → 跳过 Tester+Reviewer，省 40% token

📋 Planner max 10 轮 read + git + search_history + delegate_subtasks
✏️ Coder max 25 轮 (简单 15) read/write/patch/git + typescheck + delegate_subtasks
🧪 Tester max 10 轮 read + exec + browser + http + db
👀 Reviewer max 5 轮 read + git diff + 只读评估
⛔Planner 中止 4 类检测
