# 坦克大战 3D · TANK FRONT

纯前端 3D 坦克射击游戏（Three.js + ES Modules，无构建步骤）。

守住战场，敌军一波比一波凶——你有多少波？

## 运行

项目用 ES Modules + importmap，**必须走 HTTP 服务器**（直接双击 `index.html` 会被 Chrome 的
file:// 模块策略拦下来，白屏）。

```bash
cd tank-3d
npm start          # 等价于 npx http-server -p 8083 -c-1 .
```

或者用 Python：

```bash
cd tank-3d
python -m http.server 8083
```

然后浏览器打开：

```
http://127.0.0.1:8083/
```

`three` 通过 unpkg CDN 加载，首次打开需要联网。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W` / `S` | 前进 / 后退 |
| `A` / `D` | 车体向左 / 向右转向 |
| 鼠标移动 | 炮塔瞄准（准星指哪打哪） |
| 鼠标左键 / `空格` | 开火 |
| `Q` / `E` | 临时环视镜头（松手自动回正） |
| `P` / `Esc` | 暂停 |
| `R` | 结算/暂停界面直接重开 |

炮塔相对车体最多只能转 ±140°，正后方打不到——**被绕后就得转车体**，这是核心操作张力。
准星变红表示炮塔已经到极限角度。

## 玩法

- **波次生存**：每波刷固定数量敌军，全部击毁后进入 4.5 秒间歇，修 18 点装甲，然后下一波。
- **三种敌人**
  | 类型 | 血量 | 速度 | 伤害 | 特点 |
  | --- | --- | --- | --- | --- |
  | 侦察车 | 48 | 快 | 7 | 贴脸缠斗，数量多 |
  | 中型坦克 | 88 | 中 | 12 | 主力，保持中等距离 |
  | 重型坦克 | 155 | 慢 | 18 | 血厚伤害高，第 5 波起登场 |
- **难度曲线**：每波敌人血量 +6%、伤害 +3.2%、精度提升、数量增加，第 6/7 波同屏上限提到 6/7 辆。
- **掉落补给**（击毁敌人 17% 概率，血量低于 40% 时会保底掉维修包）
  - 🟩 维修包：+35 装甲
  - 🟧 连发：10 秒内射速提升约 3 倍
  - 🟦 护盾：9 秒内减伤 70%
- **可破坏地形**：砖块和木箱会被炮弹打碎，钢板和岩石打不穿——可以用来清理射界，也会被敌人打穿。
- **雷达小地图**：以玩家为中心、车头朝上，显示敌人朝向（红/橙三角）、障碍物和掉落物。

## 测试

```bash
node tests/smoke.mjs
```

用 puppeteer 起一个本地静态服务 + 无头 Chrome，真实加载游戏并断言：WebGL 上下文、菜单/开局流程、
驾驶位移、炮塔跟随鼠标、敌人 AI 逼近与开火、玩家炮弹命中扣血、清波后自动进下一波且难度上升、
补给拾取、暂停/继续、阵亡结算与最高分落盘、重开重置、控制台零报错、零 404。
失败时退出码为 1，并在 `tests/` 下留下各阶段截图。

> 无头环境走 SwiftShader 软件渲染，帧率只有十几帧，游戏内时间推进会明显慢于真实时间——
> 测试里等待的是游戏内条件而非固定时长。

## 实现要点

- **粒子系统**是单个 `THREE.Points` + 自定义 ShaderMaterial，逐粒子携带尺寸/颜色/透明度/重力/阻力，
  烟雾走正常混合、火花走加法混合，各 900 粒子容量，零 GC 压力。
- **碰撞**统一走 AABB 列表 + 圆-矩形推出，所有逻辑（玩家、敌人、炮弹、视线）共用一套查询。
- **确定性关卡**：地形和障碍物用 `mulberry32` 种子随机，刷新地图不变；敌人刷新用 `Math.random` 保持变化。
- **炮塔瞄准**是相机射线与高度 1.4 的水平面求交，再换算成相对车体的角度并夹在 ±140°。
- **音效全部程序化合成**（振荡器 + 噪声 + 滤波扫频），不依赖任何音频文件。
