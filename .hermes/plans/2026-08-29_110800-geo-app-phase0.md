## Proposed Approach

**Phase 0 路径**：从最底层（基础设施探针）到最上层（UI 空壳）逐层打通，每层产出可验证产物。

```
D1 环境探针 → D2 mcp-geo 接入 → D3 llms.txt 生成器
→ D4 SQLite schema → D5 浮动窗口空壳
```

**技术选型**：
- **D2**：克隆 AKzar1el/mcp-geo（43⭐ MIT TS）作为 MCP server，ACMS 端通过 native-mcp client 接入
- **D3**：自实现 Node.js llms.txt 生成器（基于 AnswerDotAI/llms-txt 规范 2588⭐）
- **D4**：复用 `server/db/connection` collection API（参 §P152 collection API 注意 insert/update 签名），建 `data/geo/` 子目录存放 SQLite 迁移
- **D5**：参考 `game-2048.js` 的 ACMSWin 注册模板（§40），独立 HTML/CSS/JS 三件套

**风险前置**：D1 探针一旦发现 proxy-browse 不能用 / agent-trace 开关失效 / db/collection 接口受限，整个 Phase 0 路径要重新评估。

## Step-by-Step Plan

### D1（今天）— 环境探针

**目标**：确认 ACMS 现有能力够支撑 GEO 应用，识别阻塞项。

**任务清单**：
1. 确认 3300 服务活着：`curl -s -o /dev/null -w "%{http_code}" http://localhost:3300/api/health`（401 = 活着，000 = 死）
2. 探针 proxy-browse 端点：`curl -H "X-API-Key: dev-key-001" http://localhost:3300/api/proxy/browse?url=https://httpbin.org/ip`（确认能用）
3. 确认 agent-trace 开关：`grep -r 'agent_trace_enabled' server/ client/ | head -10`（定位 system_configs key）
4. 读 db/connection 源码：`server/db/connection.js` 确认 collection API（insert/update/findOne/remove）
5. 读 registerViewLoader 注册模式：`grep -n registerViewLoader client/js/views/*.js | head -5`
6. 读 tool-registry 注册模式：`grep -n 'registerTool' server/tools/index.js | head -10`
7. 读 MCP client 配置位置：`grep -n 'mcp' server/services/ config.yaml 2>/dev/null | head -20`

**产出**：`data/geo/probe-report.md`（每个探针的结果 + 阻塞项标记）

### D2 — 跑通 mcp-geo 最小链路

**目标**：从 ACMS chat 流发出 mcp-geo 查询 → 返回结果 → 卡片渲染。

**任务清单**：
1. `cd C:/Users/swede/acms/external && git clone https://github.com/AKzar1el/mcp-geo.git`
2. 安装依赖：`cd mcp-geo && npm install`
3. 测试本地启动：`npx mcp-geo` 验证 server 能跑（看 stderr 输出）
4. 在 `config.yaml` 加 MCP server 配置：
   ```yaml
   mcp_servers:
     mcp-geo:
       command: node
       args: [external/mcp-geo/dist/index.js]
       env: { OPENAI_API_KEY: ${OPENAI_API_KEY} }
   ```
5. ACMS 端重启（多多手工 start.bat）后，`curl -H "X-API-Key: dev-key-001" http://localhost:3300/api/tools/runtime | grep mcp-geo` 确认注册成功
6. 写第一个 E2E 测试：`POST /api/chat/detect-and-respond` body=`{ reqId: "__free__", message: "用 mcp-geo 查一下 ChatGPT 怎么介绍 MiniMax" }`，验证 tool_calls 包含 mcp-geo
7. 截屏：浏览器打开 ACMS → 小吉输入查询 → 看到 mcp-geo 工具卡片 → 渲染结果

**产出**：`external/mcp-geo/`（克隆）+ `config.yaml` 改动 + 测试报告 `data/geo/d2-mcp-geo-report.md` + 截图

### D3 — 跑通 llms.txt 生成器

**目标**：输入 url → 抓页面 → 提取结构 → 输出标准 llms.txt 文件。

**任务清单**：
1. 克隆规范仓库：`git clone https://github.com/AnswerDotAI/llms-txt.git external/llms-txt-spec`
2. 读 `external/llms-txt-spec/README.md` 确认 v2 规范字段（Title/Summary/Detailed per H1/H2）
3. 实现 `server/tools/llms-txt-generator.js`：
   - 输入 url
   - 用 `proxyFetch` 抓 HTML（参 §39 代理基础设施）
   - 用 cheerio 解析 H1/H2 段落
   - 按 AnswerDotAI 规范生成 llms.txt 文件
   - 写入 `data/geo/llms-txt/<domain>.txt`
4. 注册为 assist 工具：
   ```javascript
   toolRegistry.registerTool({
     name: 'generate_llms_txt',
     handler: async ({ url }) => { ... },
     schema: { url: 'string' }
   });
   ```
5. E2E 测试：`generate_llms_txt({ url: 'https://acms.ai' })` → 检查输出文件存在 + 格式合规
6. 集成到 ACMS 文件浏览器：`data/geo/llms-txt/` 路径在 file-browser 里显示为特殊图标

**产出**：`server/tools/llms-txt-generator.js` + `data/geo/d3-llms-report.md`

### D4 — 建 SQLite schema

**目标**：GEO 数据 5 张表可用，CRUD 全跑通。

**任务清单**：
1. 写迁移文件：`server/db/migrations/001_geo_initial.js`

3. 写 `server/services/geo-store.js`：5 张表的 CRUD 封装（用 collection API，参 §P152）
4. 写测试脚本 `scripts/test-geo-store.js`：插 1 brand → 3 queries → 10 responses → 算 scores → 周快照 → 全链路验证

**产出**：`server/db/migrations/001_geo_initial.js` + `server/services/geo-store.js` + 测试脚本 + `data/geo/d4-schema-report.md`

## Risks, Tradeoffs, and Open Questions

### 风险（实操会遇到的）

1. **🔴 AI 引擎反爬** — ChatGPT/Perplexity 会封号
   - Phase 0 验证 proxy-browse 是否能绕过
   - 8 引擎全做的工期风险（每个都要单独验）
   - 备选：先做 ChatGPT + Claude + Perplexity 三个，其他 5 个 Phase 1 后期补

2. **🟡 多多维护 ACMS 启停** — 我不能后台 spawn（参 ACMS memory「stdin is not a tty」）
   - 每个 D2/D5 需要重启时，要通知多多手动 start.bat
   - 备选：用 `cmd //c "start /b node server/index.js"` 启动新进程，但会污染 terminal session

3. **🟡 data/acms.db 不在 git 跟踪**（参 P141）
   - D4 建的 5 张表不会随 bundle 同步到 120 服务器
   - 后续 120 部署需要单独跑迁移脚本
   - 备选：把迁移脚本 commit，120 端单独跑

4. **🟢 兄弟 agent 并行开发**（ACMS memory）
   - 改 client/index.html / chat.js / style.css 等公共文件可能冲突
   - D5 加 script 引用前先 `stat -c '%y'` 看时间戳，必要时跟兄弟协调
   - 版本号 `?v=` 抢占要让位
